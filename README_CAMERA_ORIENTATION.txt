CAMERA ORIENTATION - PORTFOLIO DEMO

Added to:
classroom_city_story_actor_demo.html

Options:
0°
90°
180°
270°

Use now:
For the laptop camera physically tilted/turned into an overhead position,
choose the angle that makes the puppet upright. 180° is likely for the
current laptop setup.

Later:
With a correctly mounted external USB webcam, use 0° if the image is already upright.

Important:
The selected angle rotates BOTH:
- the visible camera feed
- hand tracking screen coordinates

So the hand cursor remains aligned with the physical hand after rotation.

The selected angle is stored in localStorage for convenience.

Narrative Stable is not modified.
