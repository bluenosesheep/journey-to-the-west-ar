STAGE COMPOSITE TEST

Standalone software-only demo. classroom_city.html is unchanged.

How it works:
1. Capture a clean stage background with no puppet.
2. Compare later camera frames with that saved background.
3. Pixels that change enough are treated as foreground.
4. Only that foreground is placed over a software stage background.

This should let a cardboard puppet appear even when it is outside the child's body outline.
It is sensitive to camera movement, lighting changes, and large body motion.
