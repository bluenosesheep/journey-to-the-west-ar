SHADOW PUPPET STORY STAGE DEMO

This is a standalone demo. classroom_city.html is unchanged.

Concept:
- Future physical stage box: about 40 x 40 cm.
- Shadow puppet characters: about 12 cm high.
- No person segmentation is used.
- Everything inside the configured stage rectangle remains sharp.
- The classroom outside the stage is blurred / dimmed.

Open:
  stage_test.html

Modes:
- Original
- Soft Stage
- Dark Stage

Controls:
- stage width / height
- horizontal / vertical position
- outside blur
- outside dimming
- show/hide guide frame

For the current demo, use a book, paper, or box to approximate the future stage.
When the real 40 x 40 cm stage arrives, these parameters can be calibrated to it.

The current Classroom Stable is untouched.
